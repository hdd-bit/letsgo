# 탐험대 모둠 편성

현장체험학습 모둠을 아이들이 눈치 보지 않고 짤 수 있게 돕는 웹앱이에요.

- **학생**: 이름·성별 직접 적기 → 놀이공원 질문 10개 → 같이 다니고 싶은 친구 1~3명 몰래 적기 → 탐험대 유형 결과
- **선생님** (비밀번호 `1018`): 명단 관리, 결과 직접 고치기, 모둠 인원과 친구 조건 정하기, 자동 편성, 손으로 옮기기, 크게 보기·인쇄·복사

모둠은 남녀를 따로 짜고, 아래 순서로 맞춰요.
1. '꼭 같은 모둠' / '꼭 다른 모둠' 조건 지키기
2. 희망 친구를 고른 학생은 그중 **최소 1명과 같은 모둠** 되게 하기
3. 같은 유형이 한 모둠에 몰리지 않게 하기

---

## 처음 한 번만 하는 설정 (약 10분)

### 1단계 · Supabase에 저장 공간 만들기

1. https://supabase.com 에 로그인 → **New project** (이름 아무거나, 지역은 Seoul 추천)
2. 왼쪽 메뉴 **SQL Editor** → **New query**
3. 이 저장소의 `supabase.sql` 내용을 전부 복사해 붙여넣고 **Run**
   - "Success" 가 나오면 끝이에요. 여러 번 실행해도 괜찮아요.

### 2단계 · 연결 정보를 `config.js`에 넣기

1. Supabase 상단의 **Connect** 버튼(또는 **Project Settings → API**)을 눌러요.
2. 두 가지를 복사해요.
   - **Project URL** (예: `https://abcdxyz.supabase.co`)
   - **Publishable key** 또는 **anon public** 키
     ⚠️ `service_role`이나 `secret` 키는 절대 넣지 마세요.
3. GitHub에서 `config.js`를 열고 연필(✏️) 버튼 → 두 줄을 채우고 **Commit changes**

```js
window.TAMHEOM_CONFIG = {
  supabaseUrl: "https://abcdxyz.supabase.co",
  supabaseKey: "sb_publishable_xxxxxxxx"
};
```

> 여기 넣는 키는 원래 공개용이라 GitHub에 올라가도 괜찮아요. 학생 결과와 희망 친구는 비밀번호가 있어야만 볼 수 있게 데이터베이스에서 막아 두었어요.

### 3단계 · GitHub Pages로 주소 만들기

1. 저장소 **Settings → Pages**
2. **Source: Deploy from a branch**, **Branch: main / (root)** → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생겨요. 이 주소를 학생들에게 알려 주세요. (QR 코드로 만들면 편해요.)

## 수업에서 쓰는 순서

1. 학생들이 각자 기기(또는 돌아가며 한 기기)로 **학생** 탭에서 이름·성별을 적고 테스트해요. 명단을 미리 넣을 필요 없어요.
   - 같은 이름·성별로는 한 번만 제출돼요. 다시 해야 하면 선생님이 그 학생 줄을 눌러 **응답 초기화**.
   - 친구 이름은 학생이 직접 적어요. 아직 명단에 없는 이름은 ⚠로 표시되니, 모두 끝난 뒤에도 남아 있으면 그 줄을 눌러 맞는 친구를 골라 주세요.
   - 학생이 자기 이름을 잘못 적으면 다른 사람으로 들어가요. 선생님 화면에서 이름을 고치거나 지우면 돼요.
2. **선생님** 탭 → `1018` → ① 학생 명단에서 31명이 다 들어왔는지 확인. 결석생은 직접 추가하고 유형·희망 친구를 넣어 주세요.
3. ② 모둠 짜기
   - 모둠 인원: 기본은 여 `4,4,4,5` / 남 `4,4,3,3` (17명은 홀수라 한 모둠은 홀수일 수밖에 없어요)
   - 친구 조건 적기 → **모둠 짜기**
   - 노란 표시를 보고, 이름을 눌러 바꾸거나 '여기로'로 옮기기 (자동 저장)
4. **크게 보기**로 화면에 띄우거나 **인쇄** / **텍스트 복사**

## 참고

- `config.js`를 비워 두면 **체험 모드**로 열려요. 이 기기에만 저장되고, '샘플 학생 31명으로 연습하기'로 미리 써 볼 수 있어요.
- 비밀번호는 선생님 화면의 '비밀번호 바꾸기'에서 바꿀 수 있어요. 10번 연속 틀리면 10분 동안 잠겨요.
- 이름 목록(이름·성별·제출 여부)은 주소를 아는 사람이면 볼 수 있어요. 유형·답·희망 친구는 비밀번호가 있어야 보여요.
- 다른 학생 이름으로 장난 제출을 하면 그 학생 이름이 '완료'로 잠겨요. 이럴 땐 선생님이 응답 초기화를 해 주세요.
- 크롬 자동 번역이 화면을 망가뜨리지 않도록 번역 꺼짐 표시를 넣어 두었어요.
- 새 학기에 처음부터 다시 쓰려면 Supabase **SQL Editor**에서 실행:
  ```sql
  delete from public.tm_students; delete from public.tm_settings;
  ```
