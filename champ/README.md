# 챔피언반 역할 지원 (일인일역)

주소: **https://hdd-bit.github.io/letsgo/champ/** · 선생님 비밀번호 `1018`

부서 5개(교육챔·환경챔·문화챔·재정챔·안전챔)에 지원하고, 선생님이 지원서를 보고 배정하는 앱이에요.
탐험대와 같은 Supabase 프로젝트를 쓰지만 표는 `ch_`로 따로 있어서 섞이지 않아요.

## 처음 한 번
Supabase **SQL Editor**에 `champ/supabase.sql` 전체를 붙여넣고 **Run**.
→ 학생 29명, 9월 배정(포스터 기준), 부서별 하는 일, 10월 회차(준비 중)가 들어가요. 여러 번 실행해도 괜찮아요.

## 매달 쓰는 순서
1. **① 회차·월급** → `+ 새 회차 (다음 달)` (지난달 월급표가 복사돼요) → 월급·불량 시 월급·정원 고치기
   - `+5챔`, `+10%` 버튼으로 한꺼번에 올리고 내릴 수 있어요.
   - 재정챔 정원은 최대 6명. `정원 고르게 맞추기`를 누르면 인원수에 맞게 나눠요.
2. 진행 단계를 **지원 받기**로 → 학생들이 각자 기기로 지원서 작성
   - 이름 → 월급 안내 → 지난달 부서 → 1지망(장점·각오·열심도) → 2지망 → 제출
3. **마감 · 배정** → **② 지원서·배정** → `자동 초안 만들기` → 이름을 눌러 지원서를 읽고 부서 옮기기, 맡은 일 적기
   - 자동 초안: 1지망 우선, 정원이 넘치면 지난달 그 부서가 아니었던 친구 → 열심히 점수 높은 친구 순, 남으면 2지망, 그래도 안 되면 미배정
   - '지난달 같음', '1지망/2지망', 정원 초과·불균형 경고가 표시돼요.
4. **결과 공개** → 학생 화면에 역할표가 떠요. **④ 역할표**에서 크게 보기·인쇄·글로 복사
5. 한 달 동안 **③ 월급 계산**에서 역할 수행 체크(잘했어요/불량)와 더하기·빼기 → 받을 월급과 반 합계, 글로 복사
6. **⑤ 지난 역할 기록**에서 회차별 부서와 같은 부서 연속 횟수 확인

## 참고
- 학생 화면에는 **가장 최근 회차**만 보여요.
- 지원서 내용(장점·각오)은 비밀번호가 있어야만 보여요. 이름 목록과 제출 여부, 공개된 결과는 누구나 볼 수 있어요.
- 다른 학생 이름으로 장난 제출을 하면 선생님이 그 학생 지원서를 열어 `지원서 지우기`.
- 전학 간 학생은 **⑥ 명단·설정**에서 '쉬는 중'으로 바꾸면 기록은 남고 화면에서 빠져요.
- 비밀번호는 탐험대와 따로예요. ⑥에서 바꿀 수 있고, 10번 틀리면 10분 잠겨요.
